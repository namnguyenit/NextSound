# NextSound v0.1.1

Bản sửa lỗi cho gói Debian Ubuntu 22.04 amd64.

## Đã sửa

- Giao diện và `nextsound-doctor` nhận diện đúng AAC/LDAC trong runtime `/opt/nextsound`.
- AAC receiver marker được đóng gói cùng backend PipeWire 0.3.48 đã vá.
- Doctor phát hiện tình trạng PipeWire chỉ còn Dummy Output.
- Doctor phát hiện cạn inotify watches và đưa ra hướng dẫn khôi phục.
- Trình cài giữ nguyên phiên WirePlumber đang hoạt động nếu không thể cấp thêm inotify watch, tránh làm biến mất card âm thanh.

## Cài đặt/nâng cấp

```bash
sudo apt install ./nextsound_0.1.1-1_amd64.deb
```

Đóng và mở lại NextSound sau khi nâng cấp. Nếu Doctor báo cạn inotify, đóng bớt VS Code/IDE rồi chạy:

```bash
systemctl --user restart wireplumber
```

## Phạm vi tương thích

Ubuntu 22.04 x86_64, PipeWire 0.3.48 và WirePlumber 0.4.
