# NextSound v0.1.2

Bản ổn định thay thế v0.1.1 cho Ubuntu 22.04 amd64.

## Đã sửa

- Kiểm tra 64 inotify watches dự phòng thay vì chỉ một watch.
- Không restart WirePlumber nếu tài nguyên không đủ để kích hoạt ALSA và BlueZ an toàn.
- Giữ nguyên các sửa lỗi nhận diện AAC/LDAC trong runtime `/opt/nextsound` từ v0.1.1.

## Cài đặt/nâng cấp

```bash
sudo apt install ./nextsound_0.1.2-1_amd64.deb
```

Nếu Doctor báo thiếu inotify capacity, đóng bớt VS Code/IDE rồi chạy lại:

```bash
systemctl --user restart wireplumber
```

Không cần khởi động lại máy.
