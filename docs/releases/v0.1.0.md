# NextSound v0.1.0

Release công khai đầu tiên của NextSound — biến máy tính Ubuntu thành loa Bluetooth A2DP.

## Tính năng

- Nhận âm thanh từ điện thoại bằng SBC, AAC hoặc LDAC.
- Phát ra loa tích hợp, HDMI, USB DAC hoặc tai nghe Bluetooth.
- Điều chỉnh âm lượng riêng 0–150%.
- Hiển thị codec và thông số thương lượng thực tế.
- Giữ codec tai nghe độc lập với codec receiver của điện thoại.
- Credit và watermark **Made by TrungCao**.

## Tải xuống

- `nextsound_0.1.0-1_amd64.deb`: bộ cài Ubuntu 22.04 amd64.
- `SHA256SUMS`: checksum xác thực file tải về.
- GitHub tự cung cấp source archive `.zip` và `.tar.gz`.

## Cài đặt

```bash
sha256sum --check SHA256SUMS
sudo apt install ./nextsound_0.1.0-1_amd64.deb
systemctl --user daemon-reload
systemctl --user restart wireplumber
```

## Phạm vi tương thích

Gói binary này được build và kiểm thử cho Ubuntu 22.04 x86_64, PipeWire 0.3.48 và WirePlumber 0.4. Không cài ép trên Ubuntu 24.04, ARM64 hoặc distro có ABI PipeWire khác.

## Thành phần nhúng

- Backend SPA/PipeWire 0.3.48 đã vá directional codec và decode buffer.
- AAC decoder dựa trên FDK AAC 2.0.2.
- LDAC decoder dựa trên thiết kế PipeWire 1.6.0 và `hegdi/libldacdec` MIT.
- Thông báo giấy phép bên thứ ba nằm trong package và source repository.

## Kết quả kiểm thử

- 16 unit tests thành công.
- ShellCheck và AppStream validation thành công.
- Package md5 manifest, SHA-256, RPATH và dependency simulation thành công.
- Thực tế: Redmi Note 11 Pro phát LDAC 96 kHz stereo tới máy tính, đồng thời tai nghe `cc pro` dùng AAC.
