# Security Policy

## Supported versions

| Version | Supported |
|---|:---:|
| 0.1.x | ✅ |

## Reporting a vulnerability

Không đăng công khai token, cookie, khóa SSH, địa chỉ Bluetooth cá nhân hoặc dữ liệu nội bộ. Hãy mở GitHub Security Advisory riêng tư tại repository này và mô tả phiên bản, tác động, cách tái hiện cùng biện pháp giảm thiểu nếu có.

NextSound không yêu cầu quyền root khi chạy. Quyền quản trị chỉ dùng lúc cài gói Debian và cài dependency hệ thống.
